▶ Phase 2: Backend 구현
----------------------------------------------------

[완료] inference.py — AI 추론 로직 분리

  원본 infer_lora_video.py에서 웹 서비스에 맞게 추출.
  달라진 점:
  - tkinter(파일 다이얼로그) 완전 제거
  - 경로를 __file__ 기준 자동 계산 (어디서 실행해도 동작)
  - GPU 없을 때 CPU로 자동 전환 (autocast 조건부 적용)
  - load_models() : 서버 시작 시 한 번만 모델 로드

  핵심 함수:
    preprocess_frame()  : 이미지 → 모델 입력 텐서 변환
    predict_frame0()    : 첫 프레임에서 SMAS 마스크 자동 생성
    extract_frames()    : 영상 → PNG 프레임 시퀀스 분해
    infer_and_render()  : 전체 영상 propagation + 오버레이 합성
    process_video()     : 위 함수들을 묶은 최상위 진입점

[완료] main.py — FastAPI 서버

  API 설계 (RESTful):
    POST /api/upload          영상 파일 업로드 → job_id 반환
    GET  /api/status/{job_id} 추론 진행 상태 확인
    GET  /api/result/{job_id} 완료된 결과 영상 다운로드
    GET  /health              서버 + 모델 상태 확인

  설계 포인트:
  - 추론이 수 분 걸리므로 즉시 응답 불가
    → 업로드 시 job_id만 반환하고, 클라이언트가 폴링
  - ThreadPoolExecutor : 추론을 별도 스레드에서 실행
    (FastAPI는 async 기반이라 blocking 작업은 스레드로 분리해야 함)
  - lifespan 이벤트 : 서버 시작 시 모델 한 번만 로드
  - CORS 설정 : 프론트(5173)↔백엔드(8001) 간 통신 허용

[완료] 로컬 실행 확인
  → 직접 실행한 명령어:
      cd beauty/webpage/backend
      uvicorn main:app --reload --host 0.0.0.0 --port 8001

▶ Phase 3: Frontend 구현 (React)
----------------------------------------------------

[완료] api.js — API 호출 함수 모음

  uploadVideo(file)    : POST /api/upload
  getStatus(jobId)     : GET  /api/status/{job_id}
  fetchResultUrl(jobId): GET  /api/result/{job_id} → Blob URL 생성

  Blob URL 이란?
  서버에서 받은 영상 바이너리를 브라우저 메모리에 임시 저장하고
  video 태그에서 바로 재생할 수 있는 로컬 URL을 만드는 방식.
  (예: blob:http://localhost:5173/xxxx-xxxx)

[완료] vite.config.js — 개발 프록시 설정

  proxy: { '/api': 'http://localhost:8001' }

  왜 필요한가?
  브라우저 보안 정책(CORS)상 다른 포트(:5173 → :8001)로의
  직접 요청이 차단될 수 있음. Vite 개발 서버가 중간에서
  /api/* 요청을 백엔드로 전달해줌으로써 해결.

[완료] 컴포넌트 구성

  UploadZone.jsx  : 드래그&드롭 + 클릭 파일 선택
  StatusBadge.jsx : 상태(pending/processing/done/error) 시각화
  VideoPanel.jsx  : 원본/결과 영상 나란히 비교 + 다운로드 버튼

[완료] App.jsx — 상태 관리

  상태 흐름:
    idle → ready → uploading → pending → processing → done/error

  폴링 방식:
    setInterval(2초) 로 /api/status 주기적 호출
    → "done" 이 되면 결과 영상 로드 후 화면 표시

[완료] 다크 테마 UI 스타일링
