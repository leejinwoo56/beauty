================================================================
프로젝트 개요
================================================================
목표: B-mode 초음파 영상에서 SMAS 층을 자동으로 segmentation
방법: MedSAM2 finetuning (사용자 입력 없이 영상 입력 시 바로 탐지)
데이터: 수동 검토 완료된 라벨링 데이터 약 400 프레임
GitHub: https://github.com/leejinwoo56/beauty (폴더: medsam_finetune_lora/)

================================================================
완료된 작업
================================================================
[라벨링 파이프라인]
- annotation_tool.py: 첫 프레임 수동 segmentation 도구
- pipeline_propagate.py: MedSAM2로 이후 프레임 자동 전파
- pipeline_review.py: 마스크 수동 검토/수정 도구
- visualize_results.py: 최종 결과 영상화
- 위 파이프라인으로 라벨링 데이터 약 400 프레임 확보 완료

[사전 연구]
- SAM, MedSAM 적용 시도 → 초음파 noise로 인해 탐지 실패
- Analog 방식 SMAS 탐지 코드 구현 완료

[Finetuning 코드 구성 완료 - 2026-04-01]
- lora_medsam2.py: LoRA 모듈 구현
  - LoRAQKV: MultiScaleAttention.qkv (fused Linear) 래퍼
  - Q, V 에만 LoRA delta 적용 (K는 원본 유지)
  - apply_lora_to_model(): 모델 전체 freeze 후 qkv 레이어 교체
  - get_trainable_params(): LoRA + mask decoder 파라미터 반환
  - save/load_lora_checkpoint(): LoRA 파라미터만 저장/로드

- train_lora.py: 학습 파이프라인 구현
  - SMASDataset: result_resolution/output{N}/frames ↔ propagated_masks/output{N} 매칭
    - 전처리: grayscale→3ch 복사, 512×512 resize, 0.5% percentile clip, ImageNet 정규화
  - BCEDiceLoss: BCE + Dice Loss (1:1 비율)
  - forward_single_image(): 메모리/프롬프트 없이 단일 이미지 forward
  - 학습 루프: AdamW + linear warmup + cosine annealing
  - 검증 루프: Dice, IoU, Hausdorff(95th), Precision, Recall
  - 체크포인트: best validation Dice 기준 저장
  - 학습 로그: train_log.csv
